# Moonmark v2

빌드와 프레임워크 없이 실행되는 개인용 북마크 지도입니다. 사이트 아이콘과 그룹 이름만 차분한 그라데이션 위에 놓고, 조작할 때만 물리 효과를 보여줍니다.

## 로컬 실행

이 폴더에서 실행하세요.

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

브라우저에서 **http://127.0.0.1:8766** 를 엽니다. Python은 개발용 정적 파일 서버일 뿐 앱 자체는 서버 없이 작동합니다. `index.html`을 직접 열 수도 있지만 일관된 저장소 동작을 위해 localhost를 권장합니다.

## 사용 방법

- 빈 공간 우클릭: 사이트/그룹 추가, 검색, 확대 설정, JSON 내보내기/가져오기, 도움말
- 사이트 짧게 클릭: 새 탭에서 열기
- 그룹 짧게 클릭: 접기/펼치기
- 220ms 누른 뒤 드래그: 이동. 그룹은 소속 사이트도 함께 이동
- 빈 공간 드래그: 캔버스 이동 (콘텐츠 바깥 약 2 viewport까지)
- Ctrl/⌘ + 사이트 클릭 또는 Ctrl/⌘ + 빈 공간 드래그: 사이트 다중 선택
- Shift + 그룹 클릭 또는 Shift + 빈 공간 드래그: 그룹 다중 선택
- 선택된 그룹 하나를 길게 끌면 선택한 그룹과 소속 사이트를 함께 이동
- 사이트를 그룹 이름 위에 놓기: 그룹 소속 변경. 접힌 그룹에도 가능
- Delete/Backspace: 선택한 사이트 삭제
- Ctrl/⌘ + Z / Ctrl/⌘ + Shift + Z: Undo / Redo (세션 내 최대 60개)
- Ctrl/⌘ + V: URL 하나 빠른 추가. 로고 변경 모드에서는 이미지/텍스트 로고 붙여넣기
- 마우스 휠: 0.25–3배 확대. 메뉴에서 포인터/전체 중심 기준 선택
- N / G / / / ?: 사이트 추가 / 그룹 추가 / 검색 / 도움말
- Tab, Enter/Space: 노드 및 컨트롤 키보드 접근
- Shift + F10: 현재 포커스 노드 메뉴
- Esc: 선택, 검색, 메뉴, 편집 모드 취소

첫 화면의 예시 지도는 선택할 때만 추가되며 Undo로 되돌릴 수 있습니다. 예시 아이콘은 텍스트 로고로 만들어졌습니다. 실제 추가 사이트는 favicon을 사용합니다.

## 저장과 백업

브라우저 `localStorage`의 `visualBookmarkAtlas` 키에 자동 저장합니다. 사이트 위치, 그룹, 접힘, 로고, 최근 50회 방문과 확대 설정을 유지합니다. Undo는 새로고침 시 초기화됩니다.

같은 주소·포트·브라우저 프로필에서만 데이터가 공유됩니다. localhost 데이터와 GitHub Pages 데이터는 별개이므로 이동할 때 JSON 내보내기/가져오기를 사용하세요. JSON 가져오기는 확인 후 전체 교체하며 Undo 기록도 초기화합니다. 브라우저 데이터 삭제 전에 백업하세요. 여러 탭에서 동시 편집하면 마지막 저장이 적용됩니다.

이미지 로고는 128×128로 축소해 저장합니다. 저장소 할당량에 도달하면 안내를 표시합니다. 손상된 기존 데이터를 읽지 못할 경우 자동 덮어쓰기를 중단합니다.

## 구조

- `index.html`: 지도, 대화상자, 접근성 구조
- `style.css`: 배경, 아이콘, 메뉴 및 감소된 모션 설정
- `core.js`: 기존 데이터 모델·유효성 검사·방문 크기·Undo/Redo와 신규 그룹 배치, pan 경계, 테마 생성
- `script.js`: 이벤트, 렌더링, 물리 효과, 붙여넣기, 저장
- `assets/atlas.svg`: 앱 아이콘
- `tests/`: 외부 라이브러리 없이 실행하는 브라우저 회귀 테스트

## 검증

로컬 서버 실행 후 **http://127.0.0.1:8766/tests/** 에서 테스트합니다. 테스트는 현재 저장값을 임시로 백업하고 복구하지만, 테스트 실행 중에는 다른 탭에서 지도를 편집하지 마세요. 중간에 닫으면 복구가 완료되지 않을 수 있으므로 테스트는 별도 브라우저 프로필 또는 별도 포트에서 실행하는 편이 좋습니다.

파싱, 데이터 검증, history, 방문 크기, 실제 DOM에서 그룹/사이트 추가·편집·드래그·검색·확대·새로고침을 검증합니다. 시스템 클립보드 이미지 및 실제 마우스의 물리감은 수동 검증 항목입니다.

## GitHub Pages 준비

런타임 파일은 모두 상대 경로이며 의존성 설치나 빌드가 필요 없습니다. 원할 때 저장소 루트에 파일을 올리고 GitHub Pages의 branch 배포를 설정할 수 있습니다. 현재 작업에서는 원격 저장소 생성이나 배포를 하지 않았습니다.

## v1 범위와 제약

- 사이트 제목을 서버 없이 임의 도메인에서 읽으면 CORS 제한이 발생하므로 기본 이름은 hostname입니다. 우클릭으로 정식 이름을 입력할 수 있습니다.
- favicon은 Google favicon 서비스 → 해당 사이트 `/favicon.ico` → 첫 글자 순서로 시도합니다. 외부 이미지 요청 시 해당 도메인이 서비스에 전달되며, 네트워크가 없어도 문자 fallback과 나머지 기능은 작동합니다.
- 방문 크기는 이 앱에서 연 최근 방문 50건에 14일 지수 감쇠를 적용하며 38–54px로 제한합니다.
- 주변 반발은 임시 화면 변위이며 저장 좌표를 바꾸지 않습니다. 드래그 대상만 약한 관성 후 저장합니다.
- 그룹에 놓으면 주변 배치를 짧게 계산해 확정한 뒤 표시상의 스프링으로 정착합니다.
- `prefers-reduced-motion`에서는 관성·반발·접기 이동을 제거합니다.
- 무한 캔버스, 클라우드 동기화, 로그인, 사이트 크롤링은 없습니다. Pan은 콘텐츠 경계를 기준으로 제한됩니다.


## v2 변경과 데이터 보존

v1 파일은 `/Users/moon/space/BookMarkSite`에 유지하고, v2는 `/Users/moon/space/BookMarkSite2`에서 개발합니다. HTML/CSS/Vanilla JavaScript 구성과 기존 저장 키·데이터 version 1을 유지했습니다.

- 기존 그룹, 사이트, 로고, 방문 기록과 x/y, zoom, offsetX/Y는 그대로 읽습니다. 없는 `settings.background`만 기본값으로 채웁니다.
- 신규 그룹을 생성할 때만 소속 사이트의 실제/예상 반경을 고려해 빈 공간을 찾습니다. 기존 그룹은 움직이지 않습니다. 창 안에 다 들어가지 않으면 pan 또는 축소해서 볼 수 있습니다.
- 그룹 이동의 지연·스프링은 화면에만 적용됩니다. 최종 그룹 간 위치와 각 그룹 내부 상대 위치는 그대로 유지됩니다.
- 그룹 중심에 너무 가깝거나 먼 사이트는 평상시 최대 3px의 약한 시각적 보정만 적용합니다. 기존 저장 좌표나 직접 드래그한 위치를 자동 재배치하지 않습니다.
- 배경 테마 메뉴에서 7가지 패턴을 고르게 포함한 후보 12개를 제공합니다. 후보 클릭, 강도 슬라이더, 기본값은 즉시 적용·저장됩니다. 재생성은 후보만 바꿉니다. 완료/닫기는 선택을 취소하지 않습니다.
- 사이트와 그룹 선택은 독립적으로 유지됩니다. Delete는 기존처럼 선택된 사이트만 삭제합니다. Esc 또는 빈 공간 짧은 클릭으로 모든 선택을 해제합니다.
- 후보나 애니메이션 오프셋은 저장하지 않습니다. `prefers-reduced-motion`에서는 지연 효과도 제거됩니다.

### v1 데이터로 v2 사용하기

같은 origin(프로토콜·호스트·포트)에 업데이트하면 기존 저장값이 그대로 유지됩니다. v1(8765)과 v2(8766)를 나란히 테스트할 때는 저장소가 분리됩니다. **v1에서 데이터 내보내기 → v2에서 데이터 가져오기**로 이동하세요. 포트 분리는 기존 작업 데이터를 보호하기 위한 개발 환경 구성입니다.
